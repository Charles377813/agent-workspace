# HRMS 請假 Agent 詞彙表

本專案裡員工用一句話請假、由程式算時數與餘額、人確認後才寫入。這裡只收本專案特有的詞；寫程式、測試、文件時用粗體的詞，不用 _Avoid_ 列的說法（既有文字不回頭改）。

## 假與時間

**假別**：
請假的種類，代碼只有 `ANNUAL`（特休）、`PERSONAL`（事假）、`SICK`（病假）。
_Avoid_：假種、假期類型

**工作時段**：
平日的上午 09:00–13:00 與下午 14:00–18:00；請假時數只算起訖區間落在這兩段裡的部分，國定假日不扣除。
_Avoid_：上班時間、營業時間

**額度**：
某位員工某個**假別**某一年度的總時數與已用時數，以小時計（1 天＝8 小時）。
_Avoid_：配額

**餘額**：
**額度**的總時數減已用時數，也就是還能請的小時數。
_Avoid_：剩餘假數、假數

## 請假動作

**假單**：
一次請假的內容；**確認**畫面上待確認的也叫假單，但只有**送出**成功後才寫入資料庫（目前狀態只有 `SUBMITTED`）。
_Avoid_：申請單

**試算**：
唯讀檢查一組請假參數，算出時數與扣抵前後的**餘額**，不寫入任何資料。
_Avoid_：預覽、dry run

**送出**：
寫入一張**假單**並扣抵**額度**的動作；沒有主管簽核這一關。
_Avoid_：核准、簽核

**確認**：
官方 Client 在**送出**前，讓使用者看過**試算**結果後決定要不要送的步驟；只有明確同意才算。
_Avoid_：審核、核准

## 安全邊界

**凍結參數**：
Client 攔下高風險工具呼叫時複製下來的那一份參數；**試算**、**確認**畫面、**送出**都用同一份。
_Avoid_：暫存參數、草稿

**啟動身分**：
Client 用來無條件覆蓋 `employee_id` 的員工：終端機版來自啟動參數 `--employee`，Gradio 版可在閒置時切換。它沒有經過認證。
_Avoid_：登入者、已認證使用者
