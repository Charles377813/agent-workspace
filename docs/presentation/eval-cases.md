## A. LLM 行為評估：20 題 × 3 次（`src/hrms-leave-agent/evals/`）

- 目的：只評「模型有沒有聽懂、該不該呼叫工具」，不執行工具、不寫資料庫。
- 設定：固定今天 2026-09-13（週日）、員工 E001、模型 `claude-sonnet-5`、使用專案實際的 system prompt 與工具 schema，每題單輪對話。
- 判分：程式比對，不靠人看。`apply` 類要求假別與起訖時間**完全一致**才算對。
- 結果：57/60（95%）。19 題三次全對；#18 三次全失敗（原始紀錄 `eval-raw.txt`）。

### 重要說明（簡報不能漏）
- #18 失敗不代表系統不安全：工具 schema 沒有 `employee_id`，Client 會無條件覆蓋成 E001，這張假單只會掛在 E001 身上，仍須人按確認。Demo 實測：同一句話三次出現過「模型拒絕」（s6）、「撞到 E001 自己的假單」（s7）、「確認畫面顯示 E001」（s8），代表模型行為不穩定。
- 題目少（20 題）、由作者設計，結果只代表趨勢，不是精確準確率。
- 同日另跑過兩輪（合計每題 7 次）：#18 共失敗 5/7；#6、#8 各有 1 次沒呼叫工具改成反問（偏安全），之後未再出現。
- 評估是單輪對話；真實使用有上下文時，行為可能不同（s6 的拒絕發生在已有前一輪紀錄的對話裡）。
- 尚未涵蓋：英文、口語模糊說法（「週三那天」）、午休與下班後、國定假日、越權與施壓的變形。這是後續擴充方向。
