# SKILL.md 範本

複製下面整段到 `.claude/skills/<skill-name>/SKILL.md`，替換角括號內容，刪掉「說明：」註解行。
完成後把**整個 skill 目錄**（含 `scripts/`、`references/`、`assets/`）同步複製到 `.agents/skills/<skill-name>/`，不是只複製 `SKILL.md`。

---

```markdown
---
name: <skill-name>
description: <一句話說明做什麼>。使用時機：使用者<講 A>、<講 B>、或<在 C 情境>時套用。不適用於<近義但不同的任務>。
---

# <Skill 標題>

<一到兩句話：這個 skill 在做什麼、為什麼需要它。>

說明：需要參考既有規範時在這裡指路，例如「參考 docs/... 的 X 慣例，本檔不重複」。

## <流程 / 檢查項目>

說明：用祈使語氣，逐步寫。每步盡量附上「為什麼」。

1. **<步驟名>**：<做什麼>。<為什麼這步重要 / 常見誤區>。
2. **<步驟名>**：<做什麼>。
3. ...

## 產出格式

說明：產出格式固定時，用模板寫死，讓每次結果一致。

一律用這個模板：

# [標題]
## <區塊 1>
## <區塊 2>

## 範例

說明：放幾個實例幫模型抓到分寸，數量看需要；產出格式很單純時可以整段省略。

**範例 1**
Input: <使用者的輸入>
Output: <預期產出>

**範例 2**
Input: <...>
Output: <...>

## 邊界 / 注意事項

- <什麼情況不要做、什麼要先問使用者>
- <唯讀 skill 要註明「只回報，不主動修改，改前先確認」>
```

---

## 選用附加檔

需要時在 skill 資料夾加：

| 目錄 | 放什麼 | 主檔怎麼引用 |
|---|---|---|
| `scripts/` | 重複性、確定性的可執行腳本 | 「跑 `scripts/xxx.py` 來做 Y」 |
| `references/` | 篇幅大、按需載入的文件（>300 行要加目錄） | 「X 情況去讀 `references/x.md`」 |
| `assets/` | 產出用的模板、圖示、字型 | 「用 `assets/template.docx` 當底」 |

多領域 skill 按變體拆 `references/`，主檔只留「怎麼選」的邏輯。
